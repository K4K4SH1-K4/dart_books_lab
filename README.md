# Dart Book Labs

A structured learning repository documenting my journey toward mastering Dart through programming books, practical exercises, experiments, and continuous improvement.

## Learning Goals

- Understand Dart fundamentals and core language concepts.
- Implement solutions to book exercises independently.
- Document problem-solving approaches and debugging experiences.
- Improve code quality through refactoring.
- Maintain a history of my learning progress using Git and GitHub.

## Repository Structure

- `books/` — Book-specific exercises and solutions.
- `notes/` — General Dart notes, explanations, and references.
